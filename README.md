# 多 Agent 研究项目工作流

一套让**多个 AI agent（Claude）分工推进一个研究项目**的工作方式，由一个 Claude 担任"项目总览"统筹，你只处理真正需要你本人做的事。

它来自一个机器人方向研究项目的真实运行：项目里同时有仿真、校准、语言、真机等几条线，还有一个跑在超算上的执行端。这个仓库把那套做法整理成**可以直接照搬到新项目**的说明、模板和脚本。agent 的数量和分工按你的新项目调整。

---

## 它解决什么问题

| 没有这套工作流时 | 用了之后 |
|---|---|
| 开很多个对话，靠你在它们之间复制粘贴转述 | agent 之间**用仓库里的文件传话**，你不用转述 |
| 每个对话都要你盯着、催着才动 | 大部分 agent 是**定时任务**，自己醒来、自己看有没有新消息 |
| 决定散落在各个对话里，过几天谁也说不清 | 每个决定都写成**决策记录**，有编号、有依据，最新的一份标"最新" |
| 不知道哪些事在等你 | 只有一个文件列出**需要你做的事**，并同步到你桌面的待办 |
| 对话一长就丢上下文 | 每个 agent 有自己的 **STATE.md**，换对话、换模型都能接着干 |

## 快速开始

1. 读 [docs/01_核心理念.md](docs/01_核心理念.md)：10 分钟理解为什么这样分工。
2. 按 [docs/02_角色设计.md](docs/02_角色设计.md) 决定你的项目要几个 agent、各管什么。
3. 照 [docs/08_落地步骤.md](docs/08_落地步骤.md) 的清单建仓库目录、放模板、建定时任务。
4. 用 [templates/](templates/) 里的提示词启动"项目总览"和各个 agent。
5. 之后每天只做 [docs/06_用户的一天.md](docs/06_用户的一天.md) 里那几件事。

**想让 Claude 直接帮你搭？** 把 [SKILL.md](SKILL.md) 交给 Claude（或装成 skill），说"按这个工作流给我的新项目搭一套"，它会先问你项目情况，再生成目录、模板和定时任务。

## 适合谁

- 一个人或小团队做一个**周期几周到几个月、分好几条线**的项目：研究课题、毕业论文、复杂软件、数据分析。
- 已经在用 Claude（网页 / 桌面 app / Claude Code），希望它们**自己协作**，而不是每件事都经过你。

不太适合：一两天就能做完的小任务（直接开一个对话更快）。

## 需要什么

- 一个 Git 仓库（GitHub 私有仓库即可），作为 agent 之间的信箱。
- Claude 账号：交互对话 + 定时任务（scheduled tasks）。云端定时任务通过 GitHub 读写仓库；需要读写你本机文件的任务，要在 Claude 桌面 app 里授权文件夹。
- 可选：一台服务器 / 超算，上面装 Claude Code 作为执行端。
- 可选：本机自动同步脚本（Windows 计划任务或 Linux cron）。
