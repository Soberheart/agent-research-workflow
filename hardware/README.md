# 设备档案

我现有的真机设备、器材和计算资源。**每个机器人项目共用这一份**：新项目做真机规划前先读这里，不用每次重新清点。

- 最近核对：2026-11-17。
- 来源：现场检查、拍照、钢尺实测、采购记录；厂商标称值单独标明。
- **没列在这里的设备不要默认有**（见最下面一节）。列了但标着"口述"或"待确认"的，用之前要去现场核对。

## 每条信息的可信程度

| 标记 | 意思 |
|---|---|
| **已核实** | 现场检查、拍照或实测过 |
| **口述** | 我说实验室有，但没人到现场逐项核对型号和状态 |
| **待确认** | 还不知道，或要等下一次开机才能查到 |
| **厂商标称** | 来自厂商数据表，不是本机实测 |

## 规划时最容易踩的七条限制

1. **我的笔记本没有 GPU。** 用它控制时，真机上要用模型预测，只能事先在超算上算好带过去，或另找带 GPU 的机器。超算不在实验室局域网里，不能做在线推理。Cobot Magic 和 G1 自带的计算单元有没有可用的 GPU 还没核实。
2. **Franka 这边只有一台能自由摆放的相机。** 腕部那台有别的使用者，不能拆，能不能用要问。别的机器人自带的相机还没核对。
3. **Franka 的手指是定制的**，最大开口约 77–80 mm。换指尖要自己设计、打印、试配，留出几天。
4. **测量手段只有钢尺**，精度约 ±0.5–1 mm。要更准得借卡尺。
5. **每种机器人只有一台，几个项目共用。** 真机时间要错开；一个项目换了指尖或改了末端设置，要告诉另一个项目。UR 在别的实验室，还要另外协商。
6. **单人操作**，每次约 5 小时。急停要在手边，速度和力用保守设置。
7. **只有 Franka 的档案是核实过的，而且它的控制链路实测结果还不全**（实时内核、通信质量、末端坐标换算）。Cobot Magic、G1、UR 的信息都是口述加厂商标称，用之前先去现场核对。

## 没清点过的设备

下面这些**没有核对过有没有**，规划里要用就先去实验室确认，确认后补进本档案：

- 独立的力或力矩传感器、触觉传感器（UR 自带法兰力矩传感器是厂商标称；UR5e 上实际的配置待核实）
- 带 GPU 的工作站
- 别的相机（工业相机、事件相机、动捕）
- 卡尺、塞尺

## 怎么维护

- 这份档案只由**项目总览**改。
- 真机 agent 量到新数字、发现型号或状态变了：写进自己 `STATE.md` 的"设备档案更新"一节（写清数值、怎么量的、哪天量的）。总览汇总后更新这里，并改最上面的"最近核对"日期。
- 每条数字都写可信程度和来源日期。估计值和实测值不要混在一起。
- 这个仓库是公开的：**不写**账号名、主机名、IP、本机路径、实验室和学校的名称、未发表的研究内容。
