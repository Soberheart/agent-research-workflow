# 06 其他机器人与选型

除了 Franka Panda（见 [01](01_机械臂与夹爪.md)），我还能用到下面四台。这份档案的信息来自我的口述和厂商资料，**都还没有到现场逐项核对**，具体配置要在用之前确认。

## 1. 有哪些、谁优先

| 机器人 | 类型 | 在哪 | 优先级 | 可信程度 |
|---|---|---|---|---|
| Franka Emika Panda | 单臂，7 自由度 | 我自己的实验室 | **首选** | 已核实 |
| AgileX Cobot Magic | 双臂，带移动底盘 | 我自己的实验室 | **首选** | 口述 |
| Unitree G1 | 人形 | 我自己的实验室 | **首选** | 口述 |
| Universal Robots UR5e | 单臂，6 自由度 | 别的实验室，使用要协商 | 次要；用 UR 时默认用它 | 口述 |
| Universal Robots UR3e | 单臂，6 自由度 | 别的实验室，使用要协商 | 次要；已被另外两个项目占用，新想法默认不用 | 口述 |

选型规则：

- **先考虑自己实验室的三台。** 不用协商，随时能去。
- UR3e 和 UR5e 各只有一台，都是**单臂单机，不适合双臂任务**。
- 要用 UR 时，新想法默认用 **UR5e**。UR3e 主要被另外两个项目占用，除非有特别的理由。
- UR 的机时要和对方实验室协商，方案里把协商和等待的时间算进去。

## 2. 按任务选哪台

| 任务需要 | 先看 | 说明 |
|---|---|---|
| 单臂桌面操作 | Franka | 档案最全，控制链路已搭好 |
| 双臂协作、遥操作采集示教数据、模仿学习 | Cobot Magic | 自带主从臂，本来就是为采集数据设计的 |
| 全身动作、行走、人形平台上的操作 | G1 | 先确认是哪个版本、有没有灵巧手、能不能二次开发 |
| 法兰端要有力和力矩信号、或要更高的重复精度 | UR5e | 厂商标称自带法兰力矩传感器；实际装了什么要先核实，机时要协商 |
| 双臂任务 | Cobot Magic 或 G1 | **不要用两台 UR 拼**，它们各只有一台且不在一处 |

## 4. Unitree G1

人形机器人。**我们这台是基础版还是 EDU 版还没确认**，两者差别很大：

| 项目 | 基础版 | EDU 版 |
|---|---|---|
| 身高 / 体重 | 1270 mm / 约 35 kg | 1270 mm / 35 kg 以上 |
| 自由度 | 23 | 23–43，看选配 |
| 每条腿 / 腰 / 每条手臂 | 6 / 1 / 5 | 6 / 1（可加 2）/ 5（可升级到 7） |
| 手 | 没有 | 可选 Dex3-1 三指灵巧手（7 自由度，带触觉） |
| 手臂最大负载 | 约 2 kg | 约 3 kg，随手臂伸出的姿态变化 |
| 行走速度 | 最高 2 m/s | 最高 2 m/s |
| 电池 | 9000 mAh 快拆，约 2 小时 | 同左 |
| 深度相机 | Intel RealSense D435 或 D435i | 同左 |
| 激光雷达 | Livox MID-360 | 同左 |
| 计算 | 8 核 CPU | 另有 Jetson Orin NX 开发单元 |
| 二次开发 | 手册里没列 | 支持 |

以上是厂商手册里的标称值。

用之前要确认：

- 是基础版还是 EDU 版；EDU 是哪一档。
- 有没有灵巧手，是哪一种。
- 能不能二次开发、有没有开发用的计算单元。
- 保护架或吊架有没有，场地够不够它走动。

人形平台摔倒的风险比固定机械臂大得多。真机方案里要单独写保护措施。

- 现有的笔记本没有独立显卡，这一点换机器人也不变。

## 6. 去现场核对时要记的

每台机器人第一次去看时，把下面这些记下来，交给总览补进档案：

1. 具体型号和版本、固件或系统版本。
2. 末端执行器：型号、开口范围、夹持力；有定制件就量尺寸、拍照（照片里放尺子）。
3. 相机：型号、数量、装在哪、能不能动。
4. 力、力矩、触觉传感器：有没有、型号、量程。
5. 控制电脑：系统、有没有 GPU、装了什么软件、我能不能在上面装东西。
6. 谁在用、什么时候能用、有什么规矩。
7. 开机走一遍最基本的动作，确认是好的。
