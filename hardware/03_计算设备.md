## 1. 我的笔记本（控制机械臂、采集相机）

| 项目 | 情况 | 可信程度 |
|---|---|---|
| 型号 | 机械革命 WUJIE | 已核实 |
| CPU / 内存 | AMD Ryzen 7 H 255（8 核 16 线程），23 GB | 已核实 |
| 显卡 | 只有核显 Radeon 780M。**没有 NVIDIA 独显，不能做本地 GPU 推理** | 已核实 |
| 系统 | Windows 和 Ubuntu 22.04.5 双系统；Ubuntu 装在外接 USB 固态盘上；Secure Boot 关闭 | 已核实 |
| 内核 | 通用内核 6.8；实时内核截至 2026-11-12 还没装好 | 待确认 |
| 有线网口 | 板载 Realtek RTL8111（PCIe），可以网线直连控制柜 | 已核实 |
| 无线 | 板载 AX210，外加一块 USB 网卡 | 已核实 |

分工：

- **Windows**：日常工作。项目总览、本机定时任务、每 20 分钟的自动同步都在这边。
- **Ubuntu**：只在做真机时用。真机 agent（交互式）在这边。

双系统一次只能开一个，所以：

- 进 Ubuntu 前，在 Windows 上手动同步一次，看到推送成功再关机。
- 回 Windows 前，确认 Ubuntu 上的改动已推送。
- 在 Ubuntu 期间，Windows 上的本机定时任务和自动同步都不跑；本机定时任务还可能被平台自动暂停，回来后要手动重新打开。

Ubuntu 上已装好的环境见 [01 机械臂与夹爪](01_机械臂与夹爪.md) §5 和 [02 相机](02_相机.md) §4。

## 3. 超算

| 项目 | 情况 | 可信程度 |
|---|---|---|
| 名称 | NSCC ASPIRE 2A | 已核实 |
| GPU | A100 | 已核实 |
| 能用到的量 | 单卡到少量几张 | 口述 |
| 调度 | PBS 排队 | 已核实 |
| 存储上限 | Home 50 GB（偏紧），Scratch 100 TB | 已核实（2026-11-13） |
| 用途 | 离线推理、仿真、渲染 | 已核实 |
| 上面的 Claude | 一个 Claude Code 会话作"执行端"，放在 tmux 里，开着 Remote Control | 已核实 |

要知道的三点：

- **它不在实验室局域网里，不能做真机上的在线推理。** 真机上要用模型预测，只能事先在超算上算好再带过去。
- **一个账号由多个项目共用。** 每个项目用自己的目录；不碰别的项目的目录；删除类操作只写路径白名单，由我点头才执行；根目录不做通配符批量操作。
- 登录后落在哪台登录节点是随机的。执行端只在其中一台上跑，进去先看主机名，不对就跳过去。

## 4. 对规划的影响

| 想做的事 | 现在能不能 | 办法 |
|---|---|---|
| 真机上实时跑神经网络 | 不能 | 事先在超算上算好候选结果带过去；或另找带 GPU 的机器 |
| 真机闭环里中途重新预测 | 不能在线做 | 预先算好几条分支；或把闭环改成"观测后查表" |
| 离线训练、大批量仿真 | 能 | 超算，写指示交给执行端 |
| 渲染图片和视频 | 能 | 超算 |
| 调用大模型 API | 能 | 在 Windows 本机跑，密钥只放环境变量 |
