# 07 踩坑记录

原型项目真实遇到的问题，按类别整理。新项目照着避开就行。

## 定时任务

| 现象 | 原因 | 解决 |
|---|---|---|
| 本机任务每次都说"连不上你的电脑" | 任务创建时没绑定电脑，或绑定了但没挂文件夹 | 在 Claude 桌面 app 里打开任务设置：打开"要求使用此计算机"，在"本地文件夹"里**亲手**加上要用的文件夹（从别处登记的文件夹不算数）。加一个上级文件夹可以一次覆盖多个仓库 |
| 本机任务被别的 agent 叫醒时连不上电脑，定时运行却正常 | 由其他定时任务发起的叫醒不带电脑权限 | 规则里写明"不要叫醒本机任务"；本机任务靠自己的定时运行；急事由交互式总览叫醒 |
| 云端任务突然"没有 add_repo 工具""GitHub 令牌无效""克隆要输用户名" | 任务被误设成"要求使用此计算机"，改到本机跑，用不上云端的 GitHub 连接；之后关掉开关也可能恢复不了 | 云端任务**不要**打开那个开关。已经坏了的，删掉重建（从一个能用 GitHub 的会话里创建，新任务会继承正常的环境） |
| 改提示词时提示"需要在连着那台电脑的对话里批准" | 本机任务的提示词受电脑签名保护 | 在连着那台电脑的对话里改；或者把会变的规则放进仓库里的 `auto_runs.md`，提示词只写"先读它" |
| 同时创建几个任务，只成功一个 | 并发创建失败 | 一个一个创建，创建后列表核对 |
| 等的文件明明到了，agent 却"无事结束" | 文件在被 `.gitignore` 排除的目录里，`git log` 看不到 | 快速检查里加上"STATE.md 里在等的本机文件出现或更新，也算新输入"；叫醒时附带的话一律要处理 |
| 桌面上的文件被"二选一"版本搞乱 | 把要让 agent 读的文件复制到了桌面 | 桌面待办里放**快捷方式**，打开原件；agent 只读原件 |

## 同步

| 现象 | 原因 | 解决 |
|---|---|---|
| 自动同步突然停了，日志里那个时间点根本没有记录 | Windows 计划任务默认"用电池时不启动"，笔记本拔了电源 | 登记任务时加 `-AllowStartIfOnBatteries -DontStopIfGoingOnBatteries` |
| 切到另一个系统后，别的 agent 读不到刚写的决策 | 切换前最后一次自动同步之后的改动还留在本机 | 切换前手动同步，看到推送成功再关机 |
| 工作区干净时自动同步不推送本地已有的提交 | 脚本只在有改动时才推 | 脚本里同时检查"领先远端几个提交" |
| 合并失败后残留 `.git/index.lock` | 没设 git 身份就 merge | 用 `git -c user.name=... -c user.email=...`；清理锁文件前确认没有 git 进程 |
| 远端地址大小写不一致被拒 | 同步脚本按字符串比对远端 URL | 克隆时用和脚本里一模一样的地址 |
| 两个 agent 同时推送互相覆盖 | 都 force push 或都改了同一文件 | 绝不 force；每个 agent 只改自己的目录；推送被拒就 rebase 一次，还不行就放弃这轮 |

## 协作

| 现象 | 原因 | 解决 |
|---|---|---|
| 执行端拉不到指示里要用的新脚本，停下了 | 发指示时代码还没推送 | 发指示前确认代码已在远端 |
| 总览以为某 agent "没更新" | 它的工作在没合并的分支上 | 检查远端所有分支，不只看 main |
| 用户不知道"转告"要转告什么 | 待办条目写得像给 agent 看的 | 条目站在用户角度写：完整路径、能直接复制的原话、"做完谁会自动读到" |
| 开了太多 agent，管理混乱 | 按任务而不是按工作线分 | 合并强相关的线，一次性任务做完就撤，暂时用不上的先暂停 |
| 跨对话直接发消息不通 | 对话之间不能互相发消息 | 用仓库当信箱 |
| agent 被问到不是它职责的事，自己顺手改了别人的文件 | 边界没写清 | 提示词里列出"只改哪些目录"；要改别人的东西就写消息 |

## 服务器上的执行端

| 现象 | 原因 | 解决 |
|---|---|---|
| 执行端会话断网就没了 | 直接在 SSH 里跑 Claude Code | 放进 tmux；开 Remote Control，可以从手机接管 |
| 两台登录节点上的 Claude Code 互相弄崩 | 共享 Home，一边的自动更新删掉了另一边正在用的版本 | 只在一台节点上运行，或关掉自动更新 |
| 执行端推送要凭据 | 服务器上没有 GitHub 写权限 | 给那一个仓库配 deploy key 或细粒度 token，不要用覆盖所有仓库的经典 token，不要在对话里粘贴 |
| 执行端"自作主张"重跑失败的作业 | 规则没写死 | 执行端的 CLAUDE.md 写明：只执行指示里写的、失败不重跑、只贴原文不下结论、删除类永远跳过 |
