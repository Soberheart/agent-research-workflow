# 10 选题准入与投稿审核

一个机器人项目在两个时间点要过关：**立项之前**过选题准入，**有了结果或成稿之后**过投稿审核。这两关都是我定的硬性要求。

| 时间点 | 做什么 | 谁做 | 用什么 |
|---|---|---|---|
| 立项之前（还只是想法） | 选题准入 | 项目总览，或查新 agent | 本文 §1、[选题准入记录模板](../templates/repo/idea_admission.md) |
| 想法成形、要定投哪里 | 投稿审核（idea 阶段） | 评审 agent（按需，新对话） | [投稿审核提示词](../templates/prompts/venue_review.md) |
| 有初步结果、完整稿 | 投稿审核 | 评审 agent | 同上 |
| 按意见修订之后 | 复审 | 评审 agent | 同上，第 5.2 节 |

## 1. 选题准入

**不满足下面两条的想法不立项。** 不建仓库、不开 agent、不约机时。

### 1.1 可接受的想法类型

必须属于下面四类之一：

1. **已有工作的 follow-up。**
2. **占坑的新问题设定**：率先提出并定义一个新问题。
3. **强基线在某类特殊任务上失效后的解决方法。**
   这里的"强基线"是广义的强：著名、通用、用的人多即可，不一定是效果最好的方法。例如 Diffusion Policy、ACT、OpenVLA、π0 / π0.5、Octo、RDT、DP3、GR00T、SmolVLA 这类被广泛使用的策略，以及被广泛使用的模型、工具链与系统。
4. **解决某一类问题的系统工程方案。**

### 1.2 底线：问题必须真实存在

问题必须经过文献筛查、真实存在。证据**只能**是下面两类之一：

- 已有论文在 limitations 或 future work 里**明确写出**的问题；
- 经过分析**客观存在**的不足或研究空白，例如 benchmark 数字表明强基线在某类任务上失效。

不算证据的：自己的直觉、"应该有人需要"、没读过原文的二手转述、语言模型凭印象给的说法。

### 1.3 怎么执行

1. 总览（或查新 agent）联网检索，读到原文，填一份[选题准入记录](../templates/repo/idea_admission.md)：
   - 属于四类中的哪一类，一句理由；
   - 问题证据：论文、章节、原句；或 benchmark 数字、出处、任务设置；
   - 读取深度（摘要 / 全文），检索失败的也记下来；
   - 最接近的几篇工作，是不是已经有人做了。
2. 记录放**私有工作区**（里面是未发表的研究路线，不进公开仓库）。
3. 两条都满足：总览把记录交给我看，我点头后，总览先写[研究框架](00_研究框架与防跑偏.md)交我严格审、冻结，再写"项目启动"决策。
4. 有一条不满足：不立项。总览告诉我差在哪，是换一类、补证据，还是放弃。
5. 证据里引用的论文和数字，后面写论文时会直接用到，所以要准确到能被别人查证。

## 2. 投稿审核

用 [投稿审核提示词](../templates/prompts/venue_review.md)。它让评审 agent 做两件事：选最合适的会议，再按那个会议的标准评审；同时复查选题准入。

### 2.1 怎么跑

- **评审 agent 用新对话**，不要让写这份文档的 agent 自己审。参与过写作的必须在报告开头声明。
- 评审 agent 要能联网检索。
- 把提示词里"PROMPT 开始"到"PROMPT 结束"之间的内容发给它，附上研究文档。
- 第 0 节由总览按实际情况填：研究阶段、今天的日期、别的在投稿件、硬性需求。实验室条件以 [`hardware/`](../hardware/README.md) 为准。
- 要更稳的判断时用多审稿人模式（3 个审稿人 + 1 个领域主席，互不读稿）。
- 修订后用复审模式，把上一轮意见一起附上。

### 2.2 结果怎么用

- 审核报告放私有工作区。
- 总览读报告，先逐条核对事实（报告里的数字、做法，和仓库里的记录对不对得上），再分成三类：要补的分析、要改的措辞、不采纳的（写明理由）。见 [09](09_机器人项目约定.md) §8。
- 报告里的"翻盘清单"和"最先做的判别性实验"由总览转成决策和任务单。要加新实验或超预算的，由我决定。
- 判别性实验的通过标准和止损条件，在看数据之前定死。

### 2.3 会议事实会过期

提示词里的会议事实表是 2026-11-17 的快照。提示词已经要求评审 agent 每次联网重新核对。过一个投稿季后，总览更新一次这张表，并改提示词开头的日期。

## 3. 投稿偏好

写在提示词第 0 节，这里列出来方便查：

- 第一档：ICME、IROS、ICRA
- 第二档：CoRL、RSS
- 第三档：ICLR、NeurIPS、ICML、AAAI、CVPR、ICCV
- 期刊备选：RA-L（全年可投）

同等对口时优先靠前的档。

提示词最后还有一段可选的"附加筛选"，是我个人挑想法的偏好（适用面广、是研究问题而不是工具、超出常识、规划避免 MPC/MPPI、有能拍成视频的演示、故事有意思）。要用的话加到步骤 H 之后，结果单独报告，不和会议结论混在一起。
