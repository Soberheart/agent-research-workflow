# 03 目录与文件约定

## 1. 三个地方

| 地方 | 放什么 | 谁能看 |
|---|---|---|
| **研究仓库**（Git，建议私有） | 代码、文档、决策、各 agent 的报告和消息 | 所有 agent |
| **私有工作区**（本机文件夹，不进 Git） | 论文路线、创新点、查新、交接文档、决策的中文副本 | 只有总览和你 |
| **桌面待办**（本机文件夹，不进 Git、不上云） | 你自己的待办清单 + 打开常用文件的快捷方式 | 你；总览负责同步 |

## 2. 研究仓库结构

```
<repo>/
├── docs/
│   ├── overview/                    ← 只有总览写，其他 agent 只读
│   │   ├── README.md                ← 规则 + "当前有效指令"表（最新在上，只有一行标"最新"）
│   │   ├── auto_runs.md             ← 自动运行规则（快速检查、叫醒、同步），改了即生效
│   │   ├── decisions/               ← 决策记录 YYYY-MM-DD<字母>_<主题>.md
│   │   └── task_cards/              ← 任务单 YYYY-MM-DD_<编号>.md
│   └── <agent>_*.md                 ← 各 agent 的长文档（方案、预注册、报告）
├── reports/
│   ├── 需要你处理.md                 ← 只有总览写：需要用户做的事（最新在上）
│   ├── README.md                    ← 每日进度和待办的索引
│   ├── reviews/YYYY-MM-DD.md        ← 每日进度（总览写）
│   ├── worklists/YYYY-MM-DD.md      ← 每日待办，开头是角色一览（总览写）
│   └── <agent>/
│       ├── STATE.md                 ← 这个 agent 的当前状态（只有它自己写）
│       ├── YYYY-MM-DD.md            ← 每日日志
│       ├── messages/                ← 它发出的消息
│       │   ├── YYYY-MM-DD_<agent>_to_overview_NN.md
│       │   ├── YYYY-MM-DD_<agent>_to_<另一个agent>_NN.md
│       │   └── YYYY-MM-DD_<agent>_to_<执行端>_NN.md
│       └── <执行端>/YYYY-MM-DD/      ← 远端执行端写回的汇报（原始输出放 raw/）
├── <各 agent 的代码目录>/
└── scripts/                         ← 同步脚本等
```

## 3. 谁能写哪里

| 目录 / 文件 | 总览 | 执行 agent | 远端执行端 |
|---|---|---|---|
| `docs/overview/` | ✅ | ❌ 只读 | ❌ |
| `reports/需要你处理.md` | ✅ | ❌（写进自己的 STATE.md，由总览汇总） | ❌ |
| `reports/<自己>/` | — | ✅ | ❌ |
| `reports/<agent>/<执行端>/` | — | ❌ | ✅ 只写汇报 |
| 自己负责的代码目录 | ❌（只读、审核） | ✅ | ❌ 只拉取 |
| 别的 agent 的代码目录 | ❌ | ❌（要改就写消息给对方或总览） | ❌ |

在每个执行 agent 的提示词里**明确列出它可以改的目录**。

## 4. 命名规则

- **日期**一律 `YYYY-MM-DD`，时间写明时区。
- **决策**：`docs/overview/decisions/2026-10-31e_user_answers.md`。同一天第二份起加字母 b、c、d…
- **消息**：`reports/L4/messages/2026-10-31_L4_to_overview_08.md`。编号按"发出方→接收方"各自往下排，**发出后不改**；要更正就另发一条。
- **执行端汇报**：`reports/L5/nscc/2026-10-31/<UTC时间戳>_instr04_OK.txt`，结果写 OK / FAILED / STOPPED_at_stepN。
- **私有副本**：决策复制一份到私有工作区，文件名用中文简称，方便你自己翻。

## 5. 不进 Git 的东西

- 凭据：`.env`、密钥文件、`*.credentials.json`——在 `.gitignore` 里写死。
- 大数据、隐私数据：放本机或服务器，仓库里只放清单和 sha256。
- **注意**：被 `.gitignore` 排除的目录，agent 用 `git log` 是看不到变化的。如果某个 agent 在等这类本机文件（比如你填好的标注表），要在规则里写明"也检查本机文件的修改时间"，见 [07 踩坑记录](07_踩坑记录.md)。
- **也注意**：如果 `.gitignore` 排除了 `*.pdf`、`*.png`，但某些 PDF/图片是实验必需的（标定板、说明图），要单独加例外，否则别的电脑拉下来就缺文件。
